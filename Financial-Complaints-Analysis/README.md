# Financial Complaints Analysis – Tableau Dashboard

## Project Overview
This project analyzes financial customer complaints using Tableau. The dashboard gives an overview of complaint volumes, response performance, product categories, submission channels, and consumer disputes.

## Objective
- Understand customer complaint patterns.
- Identify products with the highest complaints.
- Analyze complaint submission channels.
- Review response and resolution performance.

## Key Figures

| Metric | Result |
|---|---:|
| Total Complaints | 75,513 |
| Timely Response | 98.1% |
| Complaints In Progress | 283 |
| Resolved at No Cost | 84.5% |

## Key Findings

- Web is the most commonly used complaint channel (50.37%).
- Referral accounts for 29.52% of complaints.
- Credit Card has the highest product-wise complaint count (19,176).
- Checking/Savings Accounts contribute 17.79% of complaints.
- 48.93% of consumer dispute records are marked N/A.

## Conclusion
The analysis shows that most complaints are submitted through Web and Referral channels. Credit Card complaints form the largest product category. Although timely response performance is 98.1%, the high proportion of N/A dispute records needs further examination.
